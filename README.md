# AI Navigator

AI Navigator is an intelligent AI recommendation and interaction platform that helps users find the right AI tools for their tasks, compare them, and interact directly.

---

## 🚀 Quick Start

Double-click `run.bat` in the project root directory, or run manually:

### 1. Backend (FastAPI)
```powershell
cd d:\Ai-Navigator\backend
venv\Scripts\python -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload
```
- **Backend API**: [http://127.0.0.1:8000](http://127.0.0.1:8000)
- **API Docs (Swagger UI)**: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

### 2. Frontend
```powershell
cd d:\Ai-Navigator\frontend
python -m http.server 5500
```
- **Frontend App**: [http://localhost:5500](http://localhost:5500)
